# 探空氣球 × 立方衛星晶片選型資料庫（GPT 版）

此目錄整理教學探空酬載的元件候選。不是所有晶片的窮舉，也不是飛行合格清單。

## 核對原則
- 以製造商資料表核對型號、介面、量程、工作溫度與限制。
- 購買來源和價格區分裸晶片、模組與開發板；保留幣別、數量、查核日期，不含運費稅費。
- 分開評估地面原型、平流層探空氣球與軌道立方衛星。
- 工業溫度規格不等於抗輻射、真空或宇航認證。整板、電池、連接器及軟體仍需系統驗證。
- 尚未確定的任務高度、溫度、電源、預算及頻率，以待確認欄位表達，不推測正式任務需求。
- 公開內容只使用可公開的技術與供應商資訊，不含學生、內部通訊或私人研究資料。

網站及資料完成後將在本目錄提供可搜尋、篩選、比較及匯出的選型表。
