雙狹縫 × 半圓液槽
不偏折，也會改變條紋。

題目整理 / 第 15 題

雙狹縫位於半圓皿圓心 O 附近，縫距 0.020 mm。空氣中波長 650 nm 的雷射沿 y 軸入射，屏幕位於 y = 2.0 m。半圓皿注滿折射率 nL = 1.3 的液體。

依原題近似：出射光可視為由 O 發出，沿圓弧法線出液面，不發生方向偏折；忽略兩路光在空氣中的路程差。求屏幕上相鄰亮紋的間距。

以下預設為原題資料。空氣折射率取 1；650 nm 在此近似下作為參考波長 λair。

為什麼兩個屏距相同，間距還會不同？

相鄰亮紋需要光程差增加一個 λair。同一觀察角下，液體把幾何路程差乘上 nL，所以比較小的角度變化就能累積一整個週期，亮紋更密。

原題：空氣對照 65 mm；注入液體後 50 mm。兩者比值 50/65 = 1/1.3 ≈ 0.7692。

04 / WORKED SOLUTION

原題分步詳解

  1. 先把單位換成公尺。
    d = 0.020 mm = 2.0×10⁻⁵ m
    λair = 650 nm = 6.50×10⁻⁷ m
    L = 2.0 m，nL = 1.3
  2. 液體內光速降低，頻率保持不變。

    因此液體波長 λL = 650/1.3 = 500 nm。不能仍用 650 nm 去計算液體中的幾何路程差所累積的相位。

  3. 保留兩狹縫的幾何路程差。

    遠場下，到同一方向的兩路光近似平行。令「S₁ 路徑減 S₂ 路徑」的液體幾何路程差為 ΔℓL ≈ d sinθ。依題意忽略空氣中的兩路路程差，總光程差約為 nLΔℓL。

    Δφ ≈ 2πnLd sinθ / λair
    亮紋：Δφ = 2πm → nLd sinθm = mλair
  4. 用屏距把角度換成屏幕位置。

    由於沿圓弧法線出射，光線方向不改變。屏幕 x = L tanθ；小角度時 tanθ ≈ sinθ ≈ x/L。

    xm ≈ mλairL/(nLd)
    Δx ≈ (6.50×10⁻⁷×2.0)/(1.3×2.0×10⁻⁵) m
    = 0.050 m = 50 mm = 5.0 cm

    答案：相鄰亮紋間距約 5.0 公分。

若不用小角度近似，差多少？

保留原題光程模型，只把屏幕幾何改成 xm = L tan[arcsin(mλair/(nLd))]。原題中央到右側第一亮紋約 50.0156 mm，與近軸 50 mm 差約 0.0313%。

大角度時，相鄰亮紋不再等距；本題所稱「亮紋間距」採近軸結果。這個幾何比較不是完整半圓液槽的精確光學解。

把兩狹縫都視為 O，為什麼還有路程差？

這是兩種不同用途的近似：判斷圓弧入射角時，d 遠小於皿的尺度，所以用 O 代表兩縫位置；計算干涉時，仍須保留 d 所造成的一階路程差 d sinθ。若把兩個波源完全合併成同一位置、連 d 都設成零，就已經失去雙狹縫干涉的題目設定。

三個容易混淆的地方

  • 不偏折，不代表沒有相位變化。折射率仍改變速率、介質波長與光程。
  • 出液面恢復 650 nm，不代表相位差歸零。兩路進入空氣時已有不同相位；忽略空氣路程差，這個差值繼續保留。
  • 使用一種等價算法即可。可用 λL = 500 nm 與幾何路程差，或用 λair = 650 nm 與 nLΔℓ。不能把 λ 除以 n 後又把路程差乘 n，造成重複計算。

三次小實驗

  1. 恢復原題，將 n 改為 1。亮紋間距應由 50 mm 增為 65 mm。
  2. 恢復原題，將 d 從 0.020 改為 0.040 mm。亮紋間距減半為 25 mm。
  3. 恢復原題，按「右側第 1 暗紋」。觀察相位差為 π、兩向量反向、合振幅為零。再按「右側第 1 亮紋」，相位差為 2π，兩向量同向。

原題不提供半圓皿半徑，是因為採用法線出射並忽略空氣路程差的近似後，亮紋條件不需用到半徑。

模型與參考

採用相干、同頻、等振幅的理想窄雙狹縫，正入射、遠場近似；依題意 Δℓair ≈ 0、法線出射，且以 λair 作參考波長、nair ≈ 1。忽略反射、吸收、色散、偏振、有限縫寬的單縫包絡與有限 d/R 導致的微小偏折。光強 I/Imax = cos²(Δφ/2)。
