01 / READ THE QUESTION

題目不是要證明「小孔一定讓隔音完全失效」

第 11 題的情境是：門沒有確實關好時，即使縫隙看來極小，房間的隔音仍可能受到破壞。研究任務是找出開口的幾何形狀、尺寸，如何改變聲音由一側傳到另一側的行為。這裡是中文意譯；完整英文請見 IYPT 官方題目及 TYPT 官方頁。

“may become breached” · “negligibly small”

兩個關鍵片語：前者保留條件，後者要求交代比較尺度。

用字／語意焦點應如何讀如何轉成研究
Sound isolation
隔音		降低跨越邊界的聲能傳輸；室內吸音、回音消除與隔音是不同問題。先定義依變因，再決定能否量到功率、聲壓傳遞或插入損失。
room
房間		聲音可經門縫、牆板振動及其他路徑到達接收端。先量密封時的背景傳輸，避免把旁路都算成孔的貢獻。
可能／受到破壞表示隔音可顯著變差，不是隔音必然歸零，也不是每個頻率都同樣變差。比較密封與開孔的頻譜，找劣化量及成立條件。
not shut properly
門未確實關閉		提供日常現象；可用可換孔片的剛性隔板研究機制。記錄真實縫隙是否均勻、是否有曲折通道與密封條接觸。
看似可忽略的小肉眼小，不等於聲學效應小。寬度、長度、波長、黏滯層厚度都是不同尺度。同時報告開孔率 φ、最長尺寸／波長、最窄半寬／黏滯層厚。
Investigate
研究		需要可否證的關係及適用範圍，不能停留在展示「有縫就聽得到」。掃頻、重複量測、比較模型與不確定度，提出模型失效的證據。
shape and size
形狀與尺寸		須分離變因；只比較一個大圓孔與一個小狹縫，不能歸因於形狀。先等面積比較圓／方／矩形，再固定形狀縮放；另比較相同最窄寬度。
small opening
小開口		長縫可能寬度很小、長度卻不小。壁厚也是通道長度。量全寬 h、全長 w、截面積 A、壁厚 t，不能只寫一個「孔徑」。
transmission of sound
聲音的傳遞		單點聲壓受駐波、方向性與麥克風位置影響；聲壓比不必然等於能量比。固定幾何、使用參考麥克風，區分功率透射率與量測傳遞函數。
研究主軸：在什麼頻率和幾何尺度下，極少的空氣通路會主導原本很低的背景透射？等面積的形狀差異，能否由黏滯阻力與端部慣性解釋？
02 / BUILD A MODEL

由守恆定律走到可計算的模型

以下先推導，再明確指出互動程式用了哪一部分。字母相同不代表單位相同：特別要分清孔內速度與整個隔板的平均速度。

1　連續方程＋牛頓第二定律＋氣體壓縮：聲波從何而來？

在靜止、均勻空氣中，把密度、壓力與速度擾動保留到一階。質量守恆要求壓縮伴隨速度場的匯聚；動量守恆要求壓力梯度驅動加速度。近似絕熱狀態方程將密度擾動連到壓力擾動。

∂ρ′/∂t + ρ₀ ∇·u = 0
ρ₀ ∂u/∂t = −∇p′
p′ = c²ρ′，c² = γp₀/ρ₀
∇²p′ − (1/c²)∂²p′/∂t² = 0； λ = c/f，k = 2πf/c

第一式再對時間微分、代入第二式的散度及第三式，即得波動方程。ρ₀ 為平均密度（kg/m³），ρ′ 為擾動，u 為粒子速度（m/s），p′ 為聲壓（Pa），c 為聲速（m/s），γ 約為 1.4。粒子在平衡位置附近振盪，不是整團空氣以聲速穿過孔洞。

剛性壁面施加法向速度為零；真實有黏性的孔壁更要用無滑移邊界條件 u=0。開孔處則需銜接壓力與體積流量。這些邊界條件決定反射、繞射與傳輸，單靠波動方程還不夠。

2　聲壓、強度、功率與分貝：先把量測量分清楚
Ī = Re(p̂ û*)/2； W̄ = ∫ Ī·n dS
單向平面行進波：z₀ = ρ₀c， Ī = p²rms/z₀
Lp = 20 log₁₀(prms/20 μPa)
τ = Wtrans/Winc； TL = −10 log₁₀ τ

複數帽號為峰值振幅，星號為共軛；rms 是均方根，所以使用 rms 時不再乘 1/2。同截面、相同空氣、兩側單向平面波的裝置中，τ 才能寫成壓力振幅比的平方。駐波區壓力大但速度可能小，不能以 p²/z₀ 當作當地淨強度。

插入損失 IL=20 log₁₀(|p接收,參考|/|p接收,樣品|)，是同一裝置換樣品的比較；TL 是樣品的功率透射損失。一般房間的兩點聲壓級差還包含聲場與吸聲條件，不直接等於 TL。此頁未模擬房間兩點讀值。

3　為什麼小門縫能主導隔音？平行路徑的能量估算

先用一個有意簡化的工程基準：假設面積均勻受聲，牆與孔路徑的功率不相干相加，並把孔的局部功率透射率設為可調常數 τh。

φ = A/S； τw = 10−TLw/10
τtotal = (1−φ)τw + φτh
TLtotal = −10 log₁₀ τtotal

例如牆為 40 dB、開孔率 0.1%、理想透明孔 τh=1，總透射率約 0.00110，總隔音約 29.6 dB。孔的面積很少，卻已超過牆本身的聲能通量。對極高隔音牆，此估算趨近 −10 log₁₀(φτh)。

這不是孤立小孔的精確散射解；不包含開口的相位、捕獲面積與互相耦合。此模型故意不做形狀比較，也不將下一個「整片隔板正入射 τ」再乘一次 φ。

4　孔內黏滯阻抗：形狀為什麼不只由面積決定？

短而均勻截面的孔道內，把軸向壓力梯度記作 g=Δp/t，假設時間依賴 ejωt。線性化黏滯動量式為：

jωρ₀ u = g + μ∇²⊥u，孔壁 u=0
ū = H(ω)g； zh = Δp/ū = t/H(ω) + jωρ₀ βae
ae = √(A/π)，δv = √(2μ/(ρ₀ω))

μ 為動黏滯係數（Pa·s），H 是橫截面平均速度對壓力梯度的複數流動度（m²/(Pa·s)）。zh 單位是 Pa·s/m，與以體積流量定義的 ZQ=zh/A（Pa·s/m³）不同。βae 是兩端合計的有效長度補正；β 在這裡是可調的幾何近似參數，不能把圓孔的數值當作所有狹縫的精確值。

把速度展成滿足無滑移的橫向本徵函數，逐模態解受迫的一階方程，再對截面積分，可得本頁自行實作的頻域級數：

圓孔半徑 a： H = Σn≥1 [4/ζ²n] / [μζ²n/a² + jωρ₀]
矩形全長 w、全寬 h： H = (64/π⁴) Σm,n為正奇數 1 / {m²n²[μπ²(m²/w²+n²/h²) + jωρ₀]}

ζn 是 J₀ 的正零點；方孔就是 w=h。矩形奇數模態源於均勻驅動投影到正弦函數，64/π⁴ 是投影與平均的乘積。靜態圓孔極限給 zh,R=8μt/a²；長狹縫給 zh,R≈12μt/h²。因此同面積拉長時，全寬變窄，阻力可能大幅增加。高頻薄黏滯層下，核心氣體慣性占優勢，但仍有壁面耗散。

計算使用圓孔 256 項、矩形每軸 64 個奇數模態；目前頻率另以半截斷比較作數值收斂提示。這只解孔內線性黏滯流，未求解端口三維流場、熱傳導、入口黏滯損失或高聲壓噴流。

5　由邊界連續推導整片隔板的正入射透射率

模型 B：同截面 S 的兩根半無限、無反射管道，中間放剛性隔板，唯一通路為面積 A 的短孔。兩側只保留均勻平面波，用 φ=A/S 把孔內平均速度轉成整個截面的平均速度 v=φū。

左側：pL = pi + pr，v = (pi−pr)/z₀
右側：pR = pt，v = pt/z₀
pL−pR = zsv； zs = zh/φ
tp = pt/pi = 2z₀/(2z₀+zs)
rp = zs/(2z₀+zs)
τ = |tp|²； ℛ = |rp|²； α = 4z₀ Re(zs)/|2z₀+zs|²
τ + ℛ + α = 1

將 v=pt/z₀ 代回左側速度可得 pr=pi−pt，再代入壓差式，即得到 tp。這個 τ 已以整根管截面的入射功率為分母，不是「孔局部透射率」。α 是孔內黏滯耗散占比，不能稱為消失的能量。

適用於短孔、低階平面波裝置的集總近似。孔道長度或管橫向尺寸接近波長時，需要傳遞矩陣／多模態解；自由空間的單孔要另加完整輻射負載。此處不包含牆板彈性、房間模態與側向繞射。

6　有背腔時才加入「空氣彈簧」與 Helmholtz 共振

模型 C 是外側壓力源經短孔驅動剛性封閉背腔；不再是模型 B 的無反射接收管。腔內壓力假設均勻，空氣近似絕熱壓縮。流量 Q 使腔內壓力滿足 Q=jωCpc。

C = V/(ρ₀c²)； M ≈ ρ₀(t+βae)/A
pdrive − pc = ZQQ
Hc = pc/pdrive = 1/(1+jωCZQ)
若 ZQ≈R+jωM：Hc≈1/(1−ω²MC+jωRC)
fH≈c/(2π) √[A/(V(t+βae))]

程式使用頻率相依的 zh/A 計算 Hc；fH 僅為忽略黏滯質量修正的參考位置，不保證等於曲線峰值。壓力增益大於 1 可由共振儲能造成，不代表能量增益。此模型並不給腔體對另一房間的功率透射率。腔體若接近波長，均壓假設失效；熱交換會改變順應性及損耗。

7　繞射、端部補正與「哪個尺寸算小」

開口後方聲波會散開；這是繞射。有限開口的遠場方向性和孔內速度分布、相位有關，不能用「繞射很強」推論總功率一定很大。硬壁聲學通道有平面模態，不能直接套用金屬小孔的電磁截止或四次方定律。

定義 dmax/λ 檢查孔的整體緊緻性；t/λ 檢查孔道能否集總；b/δv 檢查黏滯層是否充滿孔道（圓孔 b=a；矩形 b=h/2）。另以正方形管道的第一橫向截止 fcut=c/(2√S) 檢查模型 B 的平面波條件。模型 C 假設立方腔，以 V1/3/λ 檢查均壓條件。

本頁以 0.1 作集總尺度的保守提示線，並非物理效應在此突然切換。端部補正 β 同值的等面積比較，只能隔離孔內黏滯形狀效應；要研究真實形狀的總影響，還需量測／求解形狀相依的端部補正與輻射。

04 / FROM MODEL TO EVIDENCE

把滑桿變成可以辯護的實驗

① 尺寸實驗

固定孔形、厚度與裝置，逐級縮放 A。量測頻譜，而不是只播單音聽大小。記錄實際孔尺寸與加工誤差，特別是窄縫寬度。

② 等面積形狀實驗

做圓／方／不同長寬比矩形孔片。固定 A、t、位置與音源；不要預設圓孔一定最好。比較黏滯阻力趨勢與端部補正的不確定度。

③ 模型失效實驗

改變壁厚或背腔體積，觀察峰谷位移。若厚度增加卻在某頻帶更響，檢查共振及高階模態，不能直接宣稱理論錯誤或數據錯誤。

建議量測流程

  1. 用剛性密封箱或雙管裝置搭配可換孔片，先量完全密封與開放參考。
  2. 固定喇叭、參考麥克風及接收位置；先做麥克風相對校正，關閉自動增益與降噪（若設備允許）。
  3. 以掃頻或多個純音量測；每組至少重複三次，並重新裝卸孔片以檢查密封重現性。
  4. 只把符合單向平面波條件的量測拿去對比模型 B；房間量測先稱接收聲壓傳遞函數。
  5. 變換接收點，檢查駐波；量測背景噪聲，避免低於噪聲底的結果當成真實聲壓。
  6. 畫殘差與不確定度；比較 β 的擬合值是否可用同一組參數預測新孔片。

本頁預設值是教學情境，沒有宣稱已做實體量測。標準化建築隔音測試另有裝置與程序要求。

Reporter / Opponent 的關鍵問題

  • 你比較的「小」是開孔率，還是相對波長的尺寸？長縫的長度是否被忽略？
  • 透射率以孔面積、整個隔板面積，還是入射總功率為基準？有沒有重複乘 φ？
  • 聲壓的峰值、rms 與分貝是否混用？單點聲壓差能否代表聲功率？
  • 等面積形狀效應是否其實由最窄寬度、周長、壁厚或密封差異造成？
  • 端部補正是推導、模擬還是擬合？是否用圓孔係數代替了長縫？
  • 共振來自孔道、腔體、柔性板還是房間？如何用改變幾何去區分？
  • 你的理論只驗證了數值守恆，還是也重現了獨立實驗？
高分重點：給出可驗證的條件句，例如「在本管道與頻率範圍，固定面積時，狹縫阻力隨最窄寬度減少而上升」，並展示哪裡不再成立。
