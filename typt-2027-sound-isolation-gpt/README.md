# TYPT 2027 第11題 Sound isolation — GPT 版本

2026-11-05 · v1.0 · 繁體中文獨立教學版本。

開啟 `index.html` 即可使用，沒有框架、外部程式庫或麥克風權限需求。

- 題目用字與研究意涵、完整中文意譯及官方來源。
- 連續方程、牛頓第二定律、聲波方程、聲阻抗、分貝、能量守恆與背腔共振推導。
- A：非相干功率面積加權漏聲估算。
- B：兩側無反射管道的短孔隔板，頻率相依黏滯阻抗與整片隔板透射率。
- C：外部壓力源經孔口驅動封閉立方小腔的壓力傳遞函數。
- 等面積圓、方、矩形比較，參數可調、CSV 下載、列印解說與適用範圍提示。

`verification.json` 記錄數值與瀏覽器檢查的實際範圍。`check.cjs` 需要 Node.js，會從同目錄 HTML 擷取實際計算程式，測試 729 組參數。`verify_independent.py` 需要 SciPy，交叉核對圓孔 Bessel 解與矩形靜態 Poiseuille 解。

所有結果都是理論，不是真實實驗數據。模型 B 的透射率已包含開孔率，不可再乘一次；模型 C 的壓力增益不是功率透射率。端部補正是可調近似，長孔、高階管模態、熱損耗與三維輻射未納入。
