12-1 庫侖定律 · 例題 4 · 同時滿足三個受力條件

三顆共線電荷同時平衡

題目

真空中 A 帶電 Q，B 帶電 4Q，兩者相距 d。在它們的連線上放帶電 q 的 C，希望 A、B、C 三球的合靜電力同時為零。

（1）C 距 A 多遠？（2）求 q/Q。

顯示解題引導
  1. 先看 C。若 C 在 A、B 兩球外側，兩個同號源電荷對 C 的力會不會同向？
  2. 先用 C 的平衡決定位置，再用 A 的平衡求 q。最後把結果帶回 B 檢查。
顯示完整詳解

1. 判斷 C 的位置及電性

A、B 同號，C 位於外側時兩力同向。因此 C 在兩球之間。A、B 互斥，C 必須吸引它們，所以 q 與 Q 異號。

2. 由 C 的平衡求位置

設 AC＝x，則 BC＝d−x。k|Qq|/x²＝4k|Qq|/(d−x)²。取正平方根，d−x＝2x，故 x＝d/3。

3. 由 A 的平衡求電量

A 受 B 向左的斥力 4kQ²/d²，受 C 向右的吸力 k|Qq|/(d/3)²＝9k|Qq|/d²。兩者相等，|q|/|Q|＝4/9。配合異號，q/Q＝−4/9。

4. 代回檢查 B

B 受 A 向右的斥力 4kQ²/d²，受 C 向左的吸力 4k|Qq|/(2d/3)²＝9k|Qq|/d²＝4kQ²/d²。B 的合力也為零。

講義頁碼 12-3

互動模擬

移動 C 並改變電量，觀察三顆球的受力方向。掃描時，A、B 的位置固定供比較。
