圖解 1｜水不會只往海裡流：它會循環

考點：存量與流量要分開

地球表面約七成被海水覆蓋；地球水量大約 97% 是鹹水、3% 是淡水。淡水多存在冰與地下水中，河川湖泊只占很小一部分。

海洋一邊接收河水與降水，一邊蒸發失去水。看見流入，不能就判斷總量必定增加，還必須看流出。

水量變化 = 總流入 − 總流出

太陽能推動蒸發，重力使降水、地表水與地下水往較低位置移動；地下水流動更精確地受水頭差控制。

經典連結：101基測第1題。河流一直入海，海水總量為什麼沒有一直增加？要補上「蒸發」這條回路。

圖解 2｜地下水藏在哪裡？

地下水位是飽和帶的上界。含水層既要有可儲水的孔隙，也要能讓水通過，才容易供水。

  • 補注：降雨入滲、河水入滲等。
  • 排出：抽水、泉水、流入河海等。
  • 抽水持續超過補注，局部地下水位會下降。
  • 細粒沉積層失去水的支撐後可能壓密；有些下陷不易恢復。
「地下水很多」不等於「可以無限制抽取」。砂層容易透水；黏土即使含水，也通常不易讓水快速通過。

圖解 3｜一顆石頭的旅程：風化到沉積

原地破碎／變質：風化→剝離地表：侵蝕→帶走碎屑：搬運→放下碎屑：沉積

風化發生在原地，例如溫差、結冰或樹根使岩石破裂，以及水和氣體參與的化學改變。侵蝕強調物質被剝離；搬運與侵蝕在自然環境常同時發生。

水流越快，一般越能搬動較粗大的碎屑；流速減慢時，較粗大的顆粒通常先沉積。實際情況也受流量、顆粒形狀與黏性影響。

關鍵詞：「原地」先想風化；「被帶走」想侵蝕／搬運；「流速變慢後堆積」想沉積。
看見的地形或情境判斷依據不要混淆
彎曲河道外彎通常流速較快、侵蝕較強內彎通常沉積，並非兩側都一樣
山口扇形堆積河流出山口，坡度與流速降低沖積扇在山口，三角洲在河口
水壩上游泥沙堆積水流減慢，碎屑被攔下下游泥沙供給減少，可能加劇侵蝕
海蝕崖、海蝕洞波浪侵蝕沙灘常是沉積作用結果
砂岩突出、頁岩低凹不同岩性抗風化、抗侵蝕能力不同不是單看年代新舊就能判硬度
外營力常削低高處、填平低處；內營力可使地殼抬升、產生新地形。「地表趨於平衡」不代表整個地球終將立刻變成平面。

圖解 4｜岩石分類看「怎麼形成」，不只看顏色

礦物是天然形成、具一定成分與結晶構造的固體；岩石常由一種或多種礦物組成。辨識礦物可比較硬度、條痕、解理等，不能只看外觀顏色。

變質作用通常是未完全熔融時，在溫壓等條件改變下發生再結晶等變化；若已熔成岩漿，後續冷卻形成的是火成岩。

最優先背成對例子：石灰岩 → 大理岩；頁岩 → 板岩。臺灣東部常見大理岩，不能因此把所有東部岩石都當作變質岩。
岩類形成線索例子常考辨識
火成岩岩漿／熔岩冷卻凝固花岡岩、安山岩、玄武岩相似條件下冷卻慢，晶體較容易長大；花岡岩常粗粒，玄武岩常細粒，兩者成分也不同
沉積岩沉積物壓密膠結，或化學／生物作用累積礫岩、砂岩、頁岩、石灰岩常見層理，較可能保存化石；不是每一塊都有化石
變質岩既有岩石受溫壓影響而改變大理岩、板岩、片岩常可見排列構造，但非所有變質岩都有明顯片理

圖解 5｜板塊不是只有地殼，也不是浮在岩漿海

板塊是較堅硬的岩石圈，包含地殼及部分上部地函。板塊邊界不一定沿海岸線；同一板塊可以同時包含大陸與海洋。

不能把「板塊運動」想成大陸在水中漂，也不能把軟流圈當作整層熔融的岩漿。

三種證據線索：全球地震與火山分布、海底地形、洋底岩石年齡。中洋脊持續形成新洋殼，往兩側距離越遠通常越老。

三種邊界，三種讀圖方式

典型例：中洋脊。兩側向外移，岩漿上升冷卻；脊軸附近最年輕。

有隱沒時常見海溝、火山弧；大陸碰撞可造山。不是每種聚合邊界都長得一樣。

主要是沿邊界側向錯動，通常不直接製造或消耗大面積地殼；不能說所有板塊邊界都有火山。

圖解 6｜震源、震央、規模、震度，四個詞一次分清楚

名詞回答哪個問題
震源地下哪裡開始破裂、釋出地震波？
震央震源正上方的地表位置在哪？
規模這次地震的大小是多少？同一測定定義下，一次事件以一個規模值表示
震度某地搖晃多強？同一次事件，不同地點可不同

震度受地震大小、距離、深度、地質與地形等影響。P波通常先到，S波後到；距離越遠，兩者到時差通常越大。

「規模相同」不能證明是同一地震；「震度不同」也不能證明是不同地震。101基測第39題就是這個邏輯。

斷層看相對運動，不只看哪一邊比較高

構造主要判斷常見應力
正斷層上盤相對下盤下降張力
逆斷層上盤相對下盤上升擠壓
平移斷層沿斷層面以水平錯動為主剪力
褶皺岩層彎曲，不必然斷裂常與擠壓有關

先找傾斜斷層面：面上方那塊是上盤、下方是下盤。上盤、下盤是幾何位置，不是看地表山坡的高低。

臺灣：板塊聚合，留下山脈、斷層與地震

臺灣位於歐亞板塊與菲律賓海板塊交會區域。一般教學上可把臺灣造山與兩板塊聚合理解為主軸，但附近隱沒方向並不處處相同：

  • 臺灣南方：歐亞板塊的海洋岩石圈向東隱沒至菲律賓海板塊下方。
  • 臺灣東北方：菲律賓海板塊向北隱沒至歐亞板塊下方。
  • 中央山脈、海岸山脈的形成歷程與岩性並不完全一樣，不能把整座臺灣畫成單一方向的簡單隱沒。

圖解 7｜把地層看成「事件先後順序」

  1. 疊置：未翻轉的沉積層，下面先沉積、上面後沉積。
  2. 切割：岩脈切穿某岩層，岩脈較晚；斷層切過某層，該次斷層活動較晚。
  3. 侵蝕面：被侵蝕截切的東西較早，上方覆蓋層較晚。
  4. 化石：可限制年代或推知古環境，但必須符合化石本身的意義。
  5. 題目給數字：「距今幾年」數字越大，年代越老。
石灰岩年代 ＞ 800萬年
被岩脈切穿的頁岩：600～800萬年間
「700萬年前」比「800萬年前」年輕。不能因為數字變大，就把它當作時間越晚。

化石的兩種用途

推年代：先問生物何時存在

年代範圍較短、分布廣的化石，適合用於地層對比。相同岩性不保證同時形成；不同地點的岩層也不能只憑高度相同就認定同年代。

推環境：先問牠生活在哪裡

珊瑚礁生物化石可支持過去曾有海洋環境。高山上的海洋化石，加上地層現況，可推知其後有抬升並受侵蝕露出；不能推論珊瑚原本住在山上。

古生代三葉蟲是代表性化石之一
中生代非鳥類恐龍繁盛；侏羅紀屬中生代
新生代馬、象等類群演化發展

這是代表性配對，不是說每個大類生物只出現在某一代。例如哺乳類在中生代已出現，不能說全部哺乳類都從新生代才開始。

800萬年與600萬年，誰先誰後？

題意改寫：未翻轉的岩層含800萬年前火山灰及600萬年前岩脈，判斷各層可能年代。參考上方教學重繪。

完整推理：用上下關係與切割關係夾出年代
  1. 先把沉積順序從底往上列出：石灰岩 → 火山灰 → 頁岩 → 砂岩。

5 道原創遷移練習：會背，也要能推理

以下為原創練習，並非歷屆原題。每題先用一句話回答，再展開解析。

1｜河川上游興建攔砂壩，下游海岸一定持續向海推進嗎？

不一定。壩可能攔下泥沙，使下游與海岸沉積物供給減少；若波浪侵蝕量超過沉積量，海岸反而可能後退。必須比較「供給」與「移除」，不能只知道有河流入海就下結論。

2｜一塊岩石受高溫後完全熔融，之後冷卻成岩，屬於變質岩嗎？

不是。完全熔融後形成岩漿，冷卻凝固形成火成岩。變質作用的關鍵是原有岩石在未完全熔融下受到溫壓等條件影響而改變。

3｜同一地震，甲站震度比乙站大，能說甲站測得的規模一定較大嗎？

不能。震度描述當地搖晃，規模描述事件大小。同一次地震的不同地點可以有不同震度，不能拿震度直接換成另一個規模。

4｜A層先沉積，岩脈D切入，斷層F又切斷D，最後B層平整覆蓋所有切口；依序怎麼排？

由老到新：A沉積 → D侵入 → F錯動 → 地表侵蝕／整平 → B沉積。F切過D，所以F較晚；B未被F切過且覆蓋切口，表示所觀察的那次F活動早於B。

5｜山頂發現珊瑚化石，可以推斷現在該處仍是海洋嗎？

不能。化石支持岩層形成時曾有海洋環境；現在位於高山，還需要考慮之後抬升與侵蝕的地質歷程。過去環境不等於現在環境。

段考前，能親手完成這 6 件事

  1. 畫出水循環，補上蒸發、逕流、入滲與地下水流。
  2. 用一顆石頭的故事，分清風化、侵蝕、搬運與沉積。
  3. 各舉兩種火成岩、沉積岩、變質岩，說出形成過程。
  4. 畫三種板塊邊界箭頭，配上中洋脊、海溝或斷層的線索。
  5. 用一句話區分震源／震央，以及規模／震度。
  6. 遇到地層剖面，先寫「由老到新」順序，再處理選項。
