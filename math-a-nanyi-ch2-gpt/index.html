2-1

指數函數

從指數律出發，掌握圖形、大小比較與指數方程式。

指數圖形：從 (0,1) 出發

綠線：y = 2ˣ，遞增

紅線：y = (1/2)ˣ，遞減

兩線通過 (0,1)，水平漸近線皆為 y = 0。

圖形顯示範圍有限；曲線延伸不止於圖框。

FOCUS 2-1 / 01必練

有理指數與指數律

正底數的分數次方可改寫成根式。先統一底數，再整理指數。負指數代表倒數，不是負數。

am/n = ⁿ√(am)；auav = au+v；(au)v = auv（a > 0）

易錯提醒　本章指數函數以正底數為前提；a⁰ = 1，而 a⁻¹ = 1/a。

例題 01基礎 · 原創代表題

分數次方化簡

計算 163/4 × 8−2/3。

先把 16、8 都改成以 2 為底。
一步一步解
  1. 16 = 2⁴，故 163/4 = 2³ = 8。
  2. 8 = 2³，故 8−2/3 = 2⁻² = 1/4。
  3. 相乘得 8 × 1/4 = 2。

答案：2

常見錯法　不要把 8−2/3 算成 −4。

例題 02標準 · 原創代表題

根式與代數

已知 a > 0，化簡 (a3/2 × a−1/2)² ÷ a1/3。

同底相乘加指數，相除減指數。
一步一步解
  1. 括號內為 a3/2−1/2 = a。
  2. 平方後得到 a²。
  3. 再除以 a1/3，結果為 a2−1/3。

答案：a5/3

常見錯法　括號外平方要乘上整個括號內的指數。

FOCUS 2-1 / 02必練

單調性與指數不等式

a > 1 時 aˣ 遞增；0 < a < 1 時 aˣ 遞減。同底比較指數前，先判斷底數在哪個範圍。

a > 1：au > av ⇔ u > v；0 < a < 1：au > av ⇔ u < v

易錯提醒　底數小於 1 時，指數越大，函數值越小。

例題 03標準 · 原創代表題

小於 1 的底數

解不等式 (1/3)2x−1 ≥ 27。

27 = (1/3)⁻³，底數小於 1。
一步一步解
  1. 改寫為 (1/3)2x−1 ≥ (1/3)⁻³。
  2. 因函數遞減，得到 2x − 1 ≤ −3。
  3. 解得 x ≤ −1。

答案：x ≤ −1

常見錯法　去掉指數底數時，不等號必須反向。

例題 04標準 · 原創代表題

跨底數比較

由小到大排列 A = 21/2、B = 41/3、C = (1/2)−3/4。

全部改寫成以 2 為底。
一步一步解
  1. A = 21/2，B = 22/3，C = 23/4。
  2. 因 2 > 1，只須比較 1/2、2/3、3/4。
  3. 1/2 < 2/3 < 3/4，故 A < B < C。

答案：A < B < C

常見錯法　C 的底數與指數同時含倒數、負號，須先化簡。

FOCUS 2-1 / 03必練

圖形平移、漸近線與值域

y = aˣ 的定義域是全體實數、值域為正數，通過 (0,1)，水平漸近線為 y = 0。平移與上下翻轉會一起改變值域。

y = c·ax−h + k（a > 0、a ≠ 1、c ≠ 0）：水平漸近線 y = k

易錯提醒　漸近線不是能取到的函數值；平移後未必通過 (0,1)。

例題 05標準 · 原創代表題

翻轉與平移

設 f(x) = 3 − 2x−1，求定義域、值域、水平漸近線及 y 軸截距。

先用 2x−1 > 0 判斷值域。
一步一步解
  1. 指數 x − 1 可取任意實數，定義域為 ℝ。
  2. 2x−1 > 0，因此 3 − 2x−1 < 3；可任意接近 3 且向下無界。
  3. 水平漸近線為 y = 3；f(0) = 3 − 1/2 = 5/2。

答案：定義域 ℝ；值域 (−∞,3)；漸近線 y = 3；y 軸截距 5/2

常見錯法　值域不包含 3，前面的負號使圖形遞減。

例題 06標準 · 原創代表題

由點反求參數

已知 f(x) = ax−1 + k（a > 0、a ≠ 1），且圖形通過 (1,3)、(2,5)，求 a、k。

先代入 x = 1，讓指數變成 0。
一步一步解
  1. f(1) = a⁰ + k = 1 + k = 3，所以 k = 2。
  2. f(2) = a + 2 = 5，所以 a = 3。
  3. a = 3 符合正底數且不等於 1 的條件。

答案：a = 3，k = 2

常見錯法　a⁰ 是 1，不是 0。

FOCUS 2-1 / 04必練

指數方程式與代換

可同底就同底；遇到 a²ˣ 與 aˣ 混合，令 t = aˣ，把題目變成二次方程式，但必須保留 t > 0。

af(x) = ag(x) ⇔ f(x) = g(x)；令 t = aˣ > 0

易錯提醒　解出 t 後要換回 x；負的 t 不可保留。

例題 07基礎 · 原創代表題

同底數解方程式

解 8x−1 = 4x+1。

8 = 2³，4 = 2²。
一步一步解
  1. 左式為 23x−3，右式為 22x+2。
  2. 同底且底數不為 1，故 3x − 3 = 2x + 2。
  3. 得到 x = 5，代回兩邊皆為 2¹²。

答案：x = 5

常見錯法　改底數後，括號內每一項都要乘上外面的 3 或 2。

例題 08標準 · 原創代表題

二次式代換

解 4ˣ − 5·2ˣ + 4 = 0。

令 t = 2ˣ，則 4ˣ = t²。
一步一步解
  1. 令 t = 2ˣ > 0，原式成為 t² − 5t + 4 = 0。
  2. 因式分解：(t − 1)(t − 4) = 0，所以 t = 1 或 4，兩者皆為正。
  3. 2ˣ = 1 得 x = 0；2ˣ = 4 得 x = 2。

答案：x = 0 或 2

常見錯法　4ˣ = (2ˣ)²，不是 2·2ˣ。

FOCUS 2-1 / 05應用

成長、衰減與倍增時間

固定時間乘上固定倍率，可用指數模型。若每 T 單位時間變成 r 倍，則 N(t) = N₀·r^(t/T)。

N(t) = N₀·rt/T；成長 r > 1；衰減 0 < r < 1

易錯提醒　模型中的時間單位要一致；增加 20% 代表乘以 1.2。

例題 09標準 · 原創代表題

倍增模型

某菌群初有 500 個，每 3 小時變成 2 倍。假設連續指數模型成立，求 12 小時後數量，並求達到 4000 個所需時間。

12 小時包含幾個倍增週期？
一步一步解
  1. N(t) = 500·2t/3。
  2. N(12) = 500·2⁴ = 8000。
  3. 500·2t/3 = 4000，得 2t/3 = 8 = 2³，故 t = 9。

答案：12 小時後 8000 個；9 小時達到 4000 個

常見錯法　不要把每 3 小時倍增誤寫成每小時倍增。

例題 10標準 · 原創代表題

半衰期模型

某物質初始質量 80 g，半衰期為 6 小時。求 18 小時後質量，及質量首次不超過 5 g 的時間。

每過一個半衰期乘以 1/2。
一步一步解
  1. M(t) = 80·(1/2)t/6，t ≥ 0。
  2. M(18) = 80·(1/2)³ = 10 g。
  3. 80·(1/2)t/6 ≤ 5，得 (1/2)t/6 ≤ (1/2)⁴。
  4. 因底數小於 1，t/6 ≥ 4，故首次為 t = 24 小時。

答案：18 小時後 10 g；24 小時首次不超過 5 g

常見錯法　衰減倍率是 1/2，不能用減去固定質量的線性模型。

建立指數與對數的互換，再練習運算法則、換底與常用對數。

FOCUS 2-2 / 01必練

對數定義與底數條件

對數回答「底數的幾次方等於真數？」每次運算都要確認底數正且不為 1、真數為正。

logab = c ⇔ aᶜ = b；a > 0、a ≠ 1、b > 0

易錯提醒　loga1 = 0；logaa = 1；真數不可為 0 或負數。

例題 11基礎 · 原創代表題

指對數互換

計算 log1/28 與 log9(1/3)。

把對數值分別設為未知數，再改寫成指數式。
一步一步解
  1. 設 (1/2)ᵘ = 8 = 2³，則 2⁻ᵘ = 2³，得 u = −3。
  2. 設 9ᵛ = 1/3，改寫成 3²ᵛ = 3⁻¹，得 v = −1/2。

答案：−3；−1/2

常見錯法　對數值可以是負數，真數才必須為正。

例題 12標準 · 原創代表題

未知底數

已知 loga16 = 4，求 a。

底數必須 a > 0 且 a ≠ 1。
一步一步解
  1. 由定義，a⁴ = 16。
  2. 實數四次方根有 ±2，但底數必須為正。
  3. 因此只保留 a = 2，且 2 ≠ 1。

答案：a = 2

常見錯法　不能因為 (−2)⁴ = 16 就保留負底數。

FOCUS 2-2 / 02必練

乘除、次方與對數律

同底對數的相加可合併成乘法，相減可合併成除法，係數可移成真數的次方。這些法則都建立在真數為正。

loga(MN) = logaM + logaN；loga(M/N) = logaM − logaN；loga(Mʳ) = r logaM（M,N > 0）

易錯提醒　log(M + N) 不能拆成 log M + log N。

例題 13基礎 · 原創代表題

對數合併

計算 log212 + log26 − log29。

合成一個對數，避免逐項近似。
一步一步解
  1. 同底相加變乘，相減變除。
  2. 原式 = log2(12×6÷9) = log28。
  3. 因 2³ = 8，故值為 3。

答案：3

常見錯法　不要將相加的對數改成 log₂(12 + 6)。

例題 14標準 · 原創代表題

拆開複合真數

已知 x > 0、y > 0，將 log3(27x²/√y) 展開。

分子乘法拆加法，分母拆減法。
一步一步解
  1. 原式 = log327 + log3x² − log3y1/2。
  2. 利用次方法則，得到 3 + 2 log3x − (1/2) log3y。

答案：3 + 2 log3x − (1/2) log3y

常見錯法　若未給 x > 0，log(x²) 不能直接寫成 2 log x，應考慮 2 log|x|。

FOCUS 2-2 / 03必練

換底公式與連鎖乘積

底數不同時，換成同一個底數最有效。特別留意倒數關係與中間量可約去的連鎖乘積。

logab = logcb / logca；logab · logba = 1（各底數合法，a,b ≠ 1）

易錯提醒　換底公式分子是真數的對數，分母是底數的對數。

例題 15標準 · 原創代表題

連鎖乘積

計算 log23 · log98。

將 9 與 8 分別改成 3²、2³。
一步一步解
  1. log98 = (3 log 2)/(2 log 3)。
  2. log23 = (log 3)/(log 2)。
  3. 相乘後約去 log 2、log 3，得到 3/2。

答案：3/2

常見錯法　底數的平方移到分母，不是分子。

例題 16進階 · 原創代表題

用參數表示對數

設 p = log23，以 p 表示 log612。

全部換成以 2 為底。
一步一步解
  1. log612 = log212 / log26。
  2. log212 = log2(4×3) = 2 + p。
  3. log26 = log2(2×3) = 1 + p。

答案：(2 + p)/(1 + p)

常見錯法　log₆12 不是 log₂12 − log₂6；換底是相除。

FOCUS 2-2 / 04必練

常用對數、位數與首個非零數字

本頁未標底數的 log 均以 10 為底。若 N ≥ 1，整數位數為 ⌊log N⌋ + 1；若 0 < N < 1，由相鄰的 10 的負整數次方判斷首個非零位。

10ᵏ ≤ N < 10k+1 ⇔ k ≤ log N < k+1

易錯提醒　負數的整數下取整要特別小心，例如 ⌊−4.214⌋ = −5。

例題 17標準 · 原創代表題

整數位數

已知 log 2 ≈ 0.3010，求 2⁵⁰ 是幾位整數。

先求 log(2⁵⁰)。
一步一步解
  1. log(2⁵⁰) = 50 log 2 ≈ 15.05。
  2. 因此 10¹⁵ < 2⁵⁰ < 10¹⁶。
  3. 介於這兩個數之間的正整數有 16 位。

答案：16 位

常見錯法　15.05 的整數部分是 15，但位數要加 1。

例題 18標準 · 原創代表題

小數首個非零位

已知 log 2 ≈ 0.3010，(1/2)¹⁴ 的小數點後第幾位首次出現非零數字？

先算其常用對數，再夾在相鄰 10 的次方之間。
一步一步解
  1. log((1/2)¹⁴) = −14 log 2 ≈ −4.214。
  2. 因 −5 < −4.214 < −4，所以 10⁻⁵ < (1/2)¹⁴ < 10⁻⁴。
  3. 10⁻⁵ = 0.00001，10⁻⁴ = 0.0001，因此首個非零數字在第 5 位。

答案：小數點後第 5 位

常見錯法　不能把 −4.214 直接截成 −4 後就回答第 4 位。

FOCUS 2-2 / 05進階

對數代數與平方陷阱

含 log x 的二次式可代換；但 log(x²) 的定義域與 2 log x 不同，拆對數前必須先判斷 x 的正負。

令 t = logax（x > 0）；loga(x²) = 2 loga|x|（x ≠ 0）

易錯提醒　(log x)² 是對數值的平方，log(x²) 是平方後再取對數，兩者不同。

例題 19標準 · 原創代表題

對數值的二次方程式

解 (log x)² − 3 log x + 2 = 0。

令 t = log x，並記下 x > 0。
一步一步解
  1. 定義域 x > 0。令 t = log x，得 t² − 3t + 2 = 0。
  2. (t − 1)(t − 2) = 0，所以 t = 1 或 2。
  3. log x = 1 得 x = 10；log x = 2 得 x = 100，兩者皆合法。

答案：x = 10 或 100

常見錯法　t = 1、2 不是最後的 x。

例題 20進階 · 原創代表題

真數平方保留負根

解 log2(x²) = 4。

本題只要求 x² > 0，不要求 x > 0。
一步一步解
  1. 定義域為 x ≠ 0。
  2. 由定義得 x² = 2⁴ = 16。
  3. 解得 x = 4 或 −4，兩個解的真數皆為 16。

答案：x = ±4

常見錯法　若直接改成 2 log₂x = 4，會錯誤刪去負根。

對數函數

先檢查定義域，再處理圖形、方程式與不等式；最後整合值域與情境應用。

對數圖形：先看正半軸

綠線：y = log₂x，遞增

紅線：y = log1/2x，遞減

兩線通過 (1,0)，垂直漸近線皆為 x = 0。

圖形顯示範圍有限；曲線延伸不止於圖框。

FOCUS 2-3 / 01必練

對數圖形、平移與反函數

y = logₐx 與 y = aˣ 互為反函數，圖形對稱於 y = x。對數函數定義域為正數、值域為 ℝ；垂直漸近線為 x = 0。

y = loga(x − h) + k：定義域 x > h；垂直漸近線 x = h

易錯提醒　對數函數的漸近線是垂直線；反函數要交換 x、y 後重新解出 y。

例題 21標準 · 原創代表題

平移後的截距

設 f(x) = log2(x − 1) + 2，求定義域、值域、垂直漸近線與 x 軸交點。

x 軸交點令 f(x) = 0。
一步一步解
  1. 真數 x − 1 > 0，故定義域 x > 1；值域為 ℝ。
  2. x − 1 趨近 0 的位置是 x = 1，故垂直漸近線為 x = 1。
  3. 令 log2(x − 1) + 2 = 0，得到 x − 1 = 2⁻² = 1/4。
  4. 故 x = 5/4，交點為 (5/4,0)。

答案：定義域 (1,∞)；值域 ℝ；漸近線 x = 1；交點 (5/4,0)

常見錯法　向右平移 1 後，定義域起點為 1，且不包含端點。

例題 22標準 · 原創代表題

求反函數

求 f(x) = 3x−2 + 1 的反函數及其定義域。

先移項，再取以 3 為底的對數。
一步一步解
  1. 設 y = 3x−2 + 1，則 y − 1 = 3x−2，且 y > 1。
  2. 取對數得 x = log3(y − 1) + 2。
  3. 交換 x、y，得 f⁻¹(x) = log3(x − 1) + 2。
  4. 原函數值域為 (1,∞)，即反函數的定義域。

答案：f⁻¹(x) = log3(x − 1) + 2；定義域 x > 1

常見錯法　f⁻¹(x) 不是 1/f(x)。

FOCUS 2-3 / 02必練

複合真數的定義域

每一個對數的真數都必須為正，分母不可為 0；若在分母出現對數，還要排除對數值等於 0 的位置。

logag(x)：g(x) > 0；1/logag(x)：g(x) > 0 且 g(x) ≠ 1

易錯提醒　有多個條件時要取交集，不可只檢查合併後的真數。

例題 23標準 · 原創代表題

對數分母

求 f(x) = log2(x − 1) + 1/log3(4 − x) 的定義域。

除了兩個真數為正，分母的對數值也不能等於 0。
一步一步解
  1. x − 1 > 0 得 x > 1。
  2. 4 − x > 0 得 x < 4。
  3. log3(4 − x) ≠ 0，所以 4 − x ≠ 1，即 x ≠ 3。
  4. 取交集得 (1,3) ∪ (3,4)。

答案：(1,3) ∪ (3,4)

常見錯法　漏掉 x = 3 會讓分母等於 0。

例題 24標準 · 原創代表題

二次真數

求 f(x) = log1/2(x² − 5x + 6) 的定義域。

真數要求大於 0，底數小於 1 不影響這項要求。
一步一步解
  1. 要求 x² − 5x + 6 > 0。
  2. 因式分解為 (x − 2)(x − 3) > 0。
  3. 利用數線同號區域，得 x < 2 或 x > 3。

答案：(−∞,2) ∪ (3,∞)

常見錯法　真數不能等於 0，因此 x = 2、3 都要排除。

FOCUS 2-3 / 03必練

對數方程式與驗根

解題順序：定義域 → 合併同底對數 → 轉成代數方程式 → 回原式驗根。乘積為正不代表每一個因數都為正。

logaU = logaV ⇔ U = V（U,V > 0）

易錯提醒　合併對數可能讓原本不合法的負真數混入，因此定義域不能省。

例題 25標準 · 原創代表題

相加合併與增根

解 log2(x − 1) + log2(x − 3) = 3。

先寫 x > 3，再合成乘積。
一步一步解
  1. 定義域：x − 1 > 0 且 x − 3 > 0，所以 x > 3。
  2. 合併得 log2[(x − 1)(x − 3)] = 3。
  3. (x − 1)(x − 3) = 8，整理為 x² − 4x − 5 = 0。
  4. (x − 5)(x + 1) = 0，候選解 x = 5 或 −1；只有 5 符合定義域。

答案：x = 5

常見錯法　x = −1 雖使兩個因數乘積為 8，但原來兩個對數都沒有定義。

例題 26標準 · 原創代表題

相減合併

解 log3(x + 1) − log3(x − 1) = 1。

先判斷分子與分母真數的交集。
一步一步解
  1. 定義域要求 x > 1。
  2. 合併得 log3[(x + 1)/(x − 1)] = 1。
  3. (x + 1)/(x − 1) = 3，得 x + 1 = 3x − 3。
  4. x = 2 符合 x > 1；代入原式為 log₃3 − log₃1 = 1。

答案：x = 2

常見錯法　相減是變成商，不是 log₃[(x + 1) − (x − 1)]。

FOCUS 2-3 / 04必練

對數不等式與底數反向

先圈出定義域，再看底數。a > 1 時保留不等號；0 < a < 1 時反向。最後把代數解與定義域取交集。

0 < a < 1：logaU > logaV ⇔ 0 < U < V

易錯提醒　不能只反向後解代數式，還要保留真數為正的條件。

例題 27標準 · 原創代表題

遞減對數

解 log1/2(x − 1) ≥ −2。

先將 −2 寫成 log1/24。
一步一步解
  1. 定義域：x > 1。
  2. 原式為 log1/2(x − 1) ≥ log1/24。
  3. 底數介於 0 與 1，故 x − 1 ≤ 4，得 x ≤ 5。
  4. 和 x > 1 取交集，得 1 < x ≤ 5。

答案：1 < x ≤ 5

常見錯法　x = 1 真數為 0，不可包含；x = 5 可取到等號。

例題 28進階 · 原創代表題

兩個對數比較

解 log2(x − 1) < log2(5 − x)。

兩個真數必須同時大於 0。
一步一步解
  1. 定義域為 x > 1 且 x < 5，即 1 < x < 5。
  2. 底數 2 > 1，保留不等號：x − 1 < 5 − x。
  3. 解得 x < 3；與定義域交集得 1 < x < 3。

答案：1 < x < 3

常見錯法　只回答 x < 3 會納入沒有定義的 x ≤ 1。

FOCUS 2-3 / 05應用

值域極值與對數尺度

求 logₐg(x) 的極值，可先求正真數 g(x) 的範圍，再用對數單調性；應用題要區分「對數量的差」與「原量的倍數」。

a > 1：真數越大，對數值越大；L = 10 log(I/I₀) ⇒ ΔL = 10 log(I₂/I₁)

易錯提醒　底數小於 1 時，最大真數對應最小對數值；對數尺度的差不是原量的差。

例題 29進階 · 原創代表題

二次真數求最大值

求 f(x) = log2(−x² + 4x + 5) 的定義域、最大值與值域。

先配方：−x² + 4x + 5 = 9 − (x − 2)²。
一步一步解
  1. 真數為正：9 − (x − 2)² > 0，得 −1 < x < 5。
  2. 在此範圍內，真數屬於 (0,9]，最大值 9 在 x = 2 時取得。
  3. 底數 2 > 1，對數遞增，因此最大值是 log₂9。
  4. 真數可趨近 0 的正側，對數向負方向無界，值域為 (−∞,log₂9]。

答案：定義域 (−1,5)；最大值 log₂9（x = 2）；值域 (−∞,log₂9]

常見錯法　真數最大值是 9，函數最大值是 log₂9，兩者不可混淆。

例題 30標準 · 原創代表題

分貝的倍率

聲強級定義為 L = 10 log(I/I₀)。若兩聲音的聲強級相差 20 dB，較大者的聲強是較小者的幾倍？（I₀ 為同一參考聲強）

把兩個聲強級相減，用對數律合併。
一步一步解
  1. 設 I₂ > I₁，則 L₂ − L₁ = 10[log(I₂/I₀) − log(I₁/I₀)]。
  2. 化簡為 20 = 10 log(I₂/I₁)。
  3. 因此 log(I₂/I₁) = 2，故 I₂/I₁ = 10² = 100。

答案：100 倍

常見錯法　20 dB 的差不是 20 倍，也不是 2 倍；這裡比較的是聲強，非振幅。

考前最後確認

  • 我能分辨底數大於 1 與介於 0、1 時的遞增、遞減。
  • 我會在解對數題之前，先寫出每個真數的限制。
  • 我知道 log(M + N) 不能拆成兩個對數相加。
  • 我會把代換的 t 換回 x，並驗證是否符合定義域。
