03 · 從左到右，追蹤力的變化

━ T/W━ Rₓ/W━ Rᵧ/W━ R/W

曲線固定 θ；縱軸除以 W，方便比較。虛線標出目前位置。方向角 α 由上方數值與下方公式判讀。

從題意到答案：先分清楚「誰對誰施力」

木棒長 ℓ，棒重忽略，O 是理想樞紐，P 由輕繩拉住；重物重量 W，懸掛點到 O 的水平距離為 x。原題只改變 x，W、ℓ、θ 保持不變，且 0 ≤ x ≤ ℓ、0° < θ < 90°。

木棒受到三個外力：繩在 P 處向左上拉的 T、重物的懸掛線在 x 處向下拉的 W、樞紐在 O 處向右上推的 R。嚴格說，向下的 W 是重物經懸掛線對棒的拉力，與地球對重物的重力等大。

重物自己的受力：地球對重物的重力 W 向下，懸掛線對重物的拉力 W 向上，所以重物平衡。這兩力與木棒的三力圖屬於不同受力物體；也不要把 R 與 Rₓ、Rᵧ 當作三個獨立外力相加。

1. 取 O 點力矩，先求張力

樞紐反力通過 O，對 O 不產生力矩；張力水平分量也沿木棒，不產生力矩。取逆時針為正：

ΣτO = ℓT sinθ − xW = 0
T = Wx / (ℓ sinθ)

重物右移，向下拉力的力臂 x 增大。張力的力臂 ℓ sinθ 固定，因此張力 T 必須增大，才能提供相等的反向力矩。

2. 水平與鉛直分別平衡

取右、上為正，T 的分量是 (−T cosθ, T sinθ)。

Rₓ = T cosθ = W(x/ℓ) cotθ
Rᵧ = W − T sinθ = W(1 − x/ℓ)

隨 x 增大，向左的張力分量變大，因此 Rₓ 增大；張力向上分量承擔更多重量，因此 Rᵧ 減小。Rᵧ 與 θ 無關。

R 的大小是 √(Rₓ² + Rᵧ²)。它可能先減後增，不能由「水平變大、鉛直變小」直接斷定大小單調變化。

3. 樞紐反力的方向角

α 是樞紐反力與「向右水平線」的夾角，與繩的 θ 是不同角度。

tanα = Rᵧ/Rₓ = ((ℓ − x)/x) tanθ

固定 θ 時，x 越大，(ℓ − x)/x 越小，故 α 變小。x = 0 時直接由分量得 α = 90°；x = ℓ 時 α = 0°。

反力大小的最小值出現在 x/ℓ = sin²θ，此時 Rmin = W cosθ。這是延伸討論，原題 D 問的是方向。

4. 三力三角形與作用線共點

靜力平衡要求合力為零，所以三個向量首尾相接形成封閉三角形。T 的方向固定、大小隨 x 增大，W 的長度固定向下，R 則剛好補上最後一邊。

但合力為零仍不足以保證剛體不轉動，還必須合力矩為零。本題三個非平行力平衡時，其作用線交於同一點 Q；可勾選上方選項觀察。

Q = (x, (ℓ − x) tanθ)

R 的方向沿 OQ，故 tanα = (ℓ − x) tanθ / x，與分量法一致。端點時有一力為零或兩力共線，需另外判讀。

原題四個選項的判讀

物理量關係式重物右移時原因
A · 繩張力 TWx/(ℓ sinθ)變大需增加逆時針力矩
B · 樞紐水平反力 RₓW(x/ℓ) cotθ變大抵消更大的張力水平分量
C · 樞紐鉛直反力 RᵧW(1 − x/ℓ)變小繩提供更多向上分力

試著驗證

① 固定 θ = 30°，比較中央與右端的 T。② 改變 W，三力是否等比例改變？α 是否改變？③ 固定 x/ℓ，只改變棒長，受力是否改變？力矩是否跟著改變？④ 將重物移到 x/ℓ = sin²θ，檢查 R 是否最小。

模型限制：木棒無重量、輕繩只能拉、理想樞紐不提供力偶。本頁只討論重物位於棒上；若 x > ℓ，Rᵧ 會轉為向下，原題結論的圖像需重新處理。θ 趨近 0° 時，任何 x > 0 的平衡所需張力會發散，因此控制範圍避開 0°。
