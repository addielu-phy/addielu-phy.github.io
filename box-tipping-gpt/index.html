木箱會先滑，還是先倒？

從受力圖、力矩到地面的支撐位置，讀懂同一個木箱的三個問題。拖動施力高度，觀察正向力如何一步步移向邊緣。

滑動與翻倒動畫臨界受力圖逐步計算觀念檢核教學作品集
範例 11 · 圖片中的三個小題

先把題目翻成物理語言

均勻木箱寬 b = 2 m、高 H = 4 m，重量 W = 2 kgw，放在水平地面；靜摩擦係數 μₛ = 0.5，動摩擦係數 μₖ = 0.4。在右側、離地 h 的 P 點水平向左推。

  1. 恰將滑動，同時恰將繞通過 O 的 x 軸轉動：h 是多少？
  2. 向左等速滑動，又不傾倒：h 的最大值是多少？
  3. h = 1.5 m、F = 0.8 kgw：正向力對 x 軸的力矩及其作用點距 O 多遠？

kgw 是「公斤重」，是力的單位；1 kgw = 9.80665 N。全題統一用 kgw 與 m，所以力矩單位是 kgw·m。x 軸垂直畫面；以下以畫面逆時針力矩為正。

01 / 臨界分析：看得見的支撐點

← 推力 F→ 摩擦力 f↑ 正向力 N↓ 重量 W

四支箭頭皆為「作用在木箱上」的力；箭長按力的大小繪製。木箱保持直立時 N = W。滑動的地面紋理只表示運動方向，不代表真實速度刻度。

正向力 N2.00 kgw
支撐點距 O

支撐位置：左端 O 右端 2 m

動畫採用什麼模型？

① 以很慢的加力過程追蹤靜力平衡，直到「滑動」或「翻倒」先發生；到臨界即停止加力，不把靜力公式外推為翻倒後的運動。② 預設已向左滑動，固定 F = μₖW = 0.8 kgw；未超過翻倒上限時，以等速平移呈現。③ 固定 h = 1.5 m、F = 0.8 kgw，可播放由零加到指定推力的靜態過程。

等速模式若 h > 2.5 m，會顯示「直立等速解不可行」，不畫出地面外的正向力。翻倒臨界只呈現即將翹起的狀態；沒有模擬翻倒後的角加速度、碰撞或接觸切換。滑動臨界亦不表示之後仍等速：開始滑動後摩擦力由 1 降為 0.8 kgw。

02 / 為什麼推得越高，越容易倒？

力矩 = 力 × 垂直力臂

對左下角 O 取力矩。推力的作用線是水平線，所以力臂是垂直高度 h；重量作用線是鉛直線，所以力臂是水平距離 b/2 = 1 m。

τF = +Fh
τW = −W(b/2)
τN = +Nd
τf = 0

摩擦力沿地面作用，其作用線通過 O，所以對 O 的力矩為零，並非摩擦力不存在。

地面不能把木箱向下拉

接觸面各處的小正向力可合成一支 N。支撐位置 d 必須落在底面內：0 ≤ d ≤ 2 m。

Fh + Nd − W(b/2) = 0
Nd = W(b/2) − Fh
d = b/2 − Fh/W

當 h 或 F 增大，d 減小，合力向 O 移動。到 d = 0 時，支撐已到左端；若公式算出 d < 0，就代表直立平衡無法維持。

以上對 O 的「力矩和等於零」適用本題的靜止與等速直立運動。若木箱有平移加速度，O 又不是固定慣性點，不能直接照搬此式。對一般直立、不轉動的加速滑動，應對質心取矩：d = b/2 − [F(h − H/2) + fH/2]/W。

03 / 每一步計算都攤開

共通準備：座標、受力與兩種平衡
步驟 1｜找出質心

木箱均勻，質心在幾何中心，因此水平位置 yC = 2 ÷ 2 = 1 m，高度 zC = 4 ÷ 2 = 2 m。

步驟 2｜列鉛直方向的方程式

推力、摩擦力均水平；鉛直只有 N 向上、W 向下。未離地且沒有鉛直加速度：

ΣFz = 0 → N − W = 0 → N = W = 2 kgw
步驟 3｜列水平與轉動方程式

靜止或等速時，水平合力零，故向右的摩擦力 f 等於向左的推力 F。木箱沒有角加速度，再對 O 取矩：

f − F = 0 → f = F
Fh + Nd − 2 × 1 = 0
Nd = 2 − Fh

式中的「2」代表重量的力矩 2 kgw × 1 m = 2 kgw·m，不能只當成無單位的數字。

第 (1) 題｜滑動與翻倒同時臨界 → h = 2 m
步驟 1｜算最大靜摩擦力

「恰將開始滑動」代表靜摩擦力到達上限，尚未改用動摩擦：

fs,max = μₛN
= 0.5 × 2
= 1 kgw
步驟 2｜由水平平衡求臨界推力
F = fs,max = 1 kgw

剛要滑動前，加速度仍可視為零，因此推力等於最大靜摩擦力。

步驟 3｜套入翻倒條件

「恰將繞 x 軸轉動」代表接觸合力移到 O，d = 0。此時 N 與 f 的作用線都通過 O，對 O 的力矩均為零：

Fh − W(b/2) = 0
Fh = W(b/2)
1 kgw × h = 2 kgw × 1 m
h = (2 kgw × 1 m) ÷ 1 kgw
= 2 m

答案：h = 2 m。低於 2 m 先滑；高於 2 m 先倒；等於 2 m 才同時臨界。

也可先推一般式：F滑 = μₛW，F倒 = Wb/(2h)。令兩者相等 → μₛW = Wb/(2h) → h = b/(2μₛ) = 2/(2 × 0.5) = 2 m。h = 0 時，水平推力對 O 沒有翻倒力矩，不能直接除以零。

第 (2) 題｜等速滑動而不傾倒 → h 最大為 2.5 m
步驟 1｜改用動摩擦

木箱已向左滑動，所以摩擦力向右，大小由動摩擦係數決定：

fₖ = μₖN = 0.4 × 2 = 0.8 kgw
步驟 2｜等速代表合力為零
a = 0 → ΣFy = 0
fₖ − F = 0
F = fₖ = 0.8 kgw

這是「已在滑動」的條件。從靜止只施加 0.8 kgw，靜摩擦可以抵消它，不會自行開始滑動。

步驟 3｜用支撐點仍在底面內的條件
Nd = W(b/2) − Fh
2d = 2 − 0.8h
d = (2 − 0.8h)/2
= 1 − 0.4h

上述數值式以 d、h 的單位皆為 m。向左推時 d 會向左縮小；不翻倒需要 d ≥ 0：

1 − 0.4h ≥ 0
1 ≥ 0.4h
h ≤ 1/0.4
h ≤ 2.5 m

答案：hmax = 2.5 m（臨界值）。要保留穩定餘裕，實際應取 h < 2.5 m。

在 h = 2.5 m 時，Fh = 0.8 × 2.5 = 2 kgw·m，剛好抵消重量的力矩。為何比第 (1) 題高？因為等速所需推力只有 0.8 kgw，小於滑動前的 1 kgw；較小的推力容許較大的力臂。

第 (3) 題｜正向力的力矩與位置 → 0.8 kgw·m，0.4 m
步驟 1｜先判斷木箱會不會滑
fs,max = 0.5 × 2 = 1 kgw
F = 0.8 kgw < 1 kgw

依題目初始放在地面、由靜止施力的情境，靜摩擦可提供 0.8 kgw，木箱維持靜止。此時 fₛ = 0.8 kgw，並不是每次都等於最大值 1 kgw。若木箱原先已向左滑動，此推力也恰好維持等速，以下力矩結果相同。

步驟 2｜分別算已知兩個力矩
τF = +Fh
= +(0.8 kgw)(1.5 m)
= +1.2 kgw·m（逆時針）

τW = −W(b/2)
= −(2 kgw)(1 m)
= −2 kgw·m（順時針）

摩擦力作用線經過 O，力臂 0，故 τf = 0。

步驟 3｜由力矩平衡求正向力的力矩
τF + τN + τW = 0
1.2 + τN − 2 = 0
τN = 2 − 1.2
= +0.8 kgw·m

正向力對 x 軸的力矩大小為 0.8 kgw·m，方向逆時針（+x 方向，朝向讀者）。

步驟 4｜由力矩反求作用位置

N 向上，從 O 到作用線的水平距離為 d，所以 τN = Nd：

N = W = 2 kgw
d = τN/N
= (0.8 kgw·m)/(2 kgw)
= 0.4 m

答案：τN = 0.8 kgw·m（逆時針）；合力作用在 O 右方 0.4 m 的底面上。

檢查：0 ≤ 0.4 ≤ 2，支撐點仍在底面內；0.8 × 1.5 = 1.2 < 2，推力尚未達翻倒條件。換成 SI：τN = 0.8 × 9.80665 = 7.84532 N·m ≈ 7.85 N·m。

04 / 你真的懂了嗎？

情境摩擦力施力條件臨界高度
由靜止，恰將滑動μₛW = 1 kgwF = 1 kgw2 m
已向左等速滑動μₖW = 0.8 kgwF = 0.8 kgw2.5 m
靜止，F = 0.8 kgwfₛ = F = 0.8 kgwh = 1.5 md = 0.4 m，未翻倒
木箱高 4 m，為什麼答案中沒有直接用到 4？

對底角 O 取矩，重量的力臂是「水平的半寬 1 m」，不是質心高度 2 m。箱高只限制施力位置 0 ≤ h ≤ 4 m；在一般加速平移、對質心取矩時，箱高才會明確進入公式。

正向力一定作用在底面中央嗎？

沒有推力時，由對稱性可在中央；有推力後，接觸壓力重新分配，合力位置向左移。d 是許多微小正向力合成的等效位置，不代表只有該點接觸地面，也不代表真實接觸壓力已由本題唯一決定。

試試看：h = 3 m，逐漸加力，先發生什麼？

翻倒臨界 F = 2/3 ≈ 0.667 kgw，小於滑動臨界 1 kgw，因此先倒。到該瞬間，靜摩擦只需 0.667 kgw，尚未到上限。

試試看：等速滑動時 h = 2 m，支撐位置在哪裡？

F = 0.8 kgw；d = 1 − Fh/W = 1 − (0.8 × 2)/2 = 1 − 0.8 = 0.2 m。所以第 (1) 題的 h = 2 m 並不代表等速滑動時也剛好翻倒。
