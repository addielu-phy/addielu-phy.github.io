## 特別核對的原題符號

- 多選1C：底數√3、真數⁴√24，中項log_(1/3)(1/5)，右項log_9 26。
- 多選2D：y=2^|x|、y=log_2|x|，所以不是一般指數、對數反函數；答案僅B。
- 多選3D：底數均為√2；3E的指數與對數有絕對值，對數定義域仍要求x>0。
- 多選4A～C：條件為0<a<1<b<c。
- 填充1：√27及125^[log_25(³√81)]的根號範圍。
- 填充2：第二因數是(2^6×3)^(2/3)。
- 填充6：a的指數為|x|；原式恆有零根，α與β指兩個非零根。
- 填充8：log(100x)，不是以100為底的對數。
- 填充9：第二函數是−3+log_2 x。
- 填充11：固定比例連續指數模型嚴格門檻t>32.897352853986256小時，最小整數小時33；每6小時才檢查的離散版本是36。
