例題 3 · 導體與球對稱

同心金屬球與帶電球殼

題目

半徑 a 的金屬球帶電 +q₁。外層是同心金屬球殼，內半徑 b、外半徑 c，淨電量為 +q₂，且 a < b < c。

分別求 r < a、a < r < b、b < r < c、r > c 的電場大小，並說明非零時的方向。

引導提示
  1. 先標出哪兩個區域是金屬本體。靜電平衡時，導體內部的電場是多少？
  2. 在球殼金屬內畫一同心球面。如果電場為零，球面包住的總電量應是多少？
完整詳解

1. 先判斷金屬內部

達到靜電平衡後，金屬內部 E = 0。因此 r < a 與 b < r < c 都是 0。

2. 找球殼兩表面上的電量

在 b < r < c 的金屬內取同心球形高斯面。電通量為零，包住的電量也必為零，所以 q₁ + q內表面 = 0，得 q內表面 = −q₁。球殼的淨電量是 +q₂，外表面必帶 +(q₁ + q₂)。

3. 隙間只包住內球

在 a < r < b 取同心球形高斯面。球對稱使 E 在球面上處處等大且沿徑向。E(4πr²) = q₁/ε₀，因此 E = kq₁/r²，徑向向外。

4. 球殼外包住全部淨電荷

r > c 時，E(4πr²) = (q₁ + q₂)/ε₀，得 E = k(q₁ + q₂)/r²，徑向向外。理想帶電表面 a、b、c 的兩側場值不同，應分別看左右極限。

講義頁碼 12-15

互動模擬

沿半徑移動探測點。比較金屬內、空隙和球殼外的讀值，並觀察圖上的跳變。
